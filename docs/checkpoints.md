# Самостоятельная проверка

Это контрольные результаты для исходных CSV после задания 2, до постоянных изменений задания 7. Формулировки запросов находятся в заготовках SQL. Готовых запросов здесь нет.

| Проверка | Результат |
| --- | --- |
| readers / authors / categories | 12 / 7 / 5 строк |
| books / book_authors / loans | 10 / 13 / 16 строк |
| Читатели без email | id 2, 4, 7, 10, 12 |
| Активные читатели из Казани | id 2, 5, 8 |
| Нет доступных экземпляров | книги 30, 70 |
| Три самые дорогие книги | 40, 50, 30 в этом порядке |
| Максимальный copies | книга 80, copies=5 |
| Открытые выдачи | 9 строк |
| Просроченные открытые на 2026-06-01 | выдачи 100, 103, 105, 108 |
| Возврат позже срока | выдача 109 |
| Читатели без выдач | id 3, 4, 11, 12 |
| Книги без истории выдач | id 90, 100 |
| Автор без книг | id 7 |
| Пустая категория | id 5 |
| JOIN выдач с читателями и книгами | 16 строк |
| JOIN книг с авторами | 13 строк |
| LEFT JOIN читателей с открытыми выдачами, фильтр в ON | 14 строк |
| Тот же фильтр в WHERE | 9 строк |

Число строк отчёта с LEFT JOIN может быть больше числа читателей: у одного читателя бывает несколько текущих выдач.

После заданий 5 и 6 исходные данные должны остаться прежними. После задания 7 добавляется только выдача 200, затем она закрывается: всего loans=17, открытых выдач снова 9, copies книги 10 снова 3. Ошибочная выдача 201 отсутствует.

После задания 8 copies книги 80 снова 5, обе сессии завершили транзакции. Задание 9 выполняй с ROLLBACK для примеров изменения данных.
